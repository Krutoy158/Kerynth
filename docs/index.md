# Kerynth

**Kerynth** — независимый дистрибутив Linux с собственной системой сборки, управления пакетами и установки.

Kerynth создаётся на основе исходных проектов. Основа системы задумана минимальной: графическая среда и дополнительные компоненты будут устанавливаться отдельно.

This wiki documents the architecture, development process, package format, and hardware support policy of Kerynth.

## Explore the documentation

- **Architecture** — устройство системы и её основные компоненты.
- **Build system** — сборочная инфраструктура и доступные команды.
- **Package format** — проектирование собственного формата пакетов .ker.
- **Development roadmap** — этапы разработки и критерии завершения.
- **Hardware support** — политика поддержки устройств и прошивок.

## Project repository

Исходный код, тесты и изменения проекта находятся в [GitHub-репозитории Kerynth](https://github.com/Krutoy158/Kerynth).

## Development status

Kerynth находится на ранней стадии разработки. Документация различает запланированные возможности и уже реализованные инструменты. Наличие описания функции не означает, что она уже работает в дистрибутиве.

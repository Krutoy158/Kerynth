# AETHER OS

[English version](README.md)

AETHER OS — независимый Linux-дистрибутив, который собирается из исходников upstream-проектов. В основе не будет готовой корневой системы или пакетной базы Arch, Debian, Ubuntu, Fedora, Gentoo либо другого дистрибутива.

Проект находится на ранней стадии. Сейчас в репозитории есть начальная архитектура и первая версия инструмента для проверки и загрузки исходников. Загрузочного образа пока нет.

## Текущее состояние

| Часть системы | Состояние |
|---|---|
| Архитектура и документация | Начальный вариант |
| Конфигурация сборки и загрузчик исходников | Первая реализация |
| Ядро, initramfs и загрузка | Не реализовано |
| Драйверы и firmware | Требования описаны |
| Собственный формат пакетов `.aet` | Проектирование |
| Импорт Debian `.deb` | Проектирование |
| Установщик и графические профили | Запланировано |
| ISO | Пока нет |

## Техническое направление

- Сначала x86_64 и upstream Linux kernel.
- Для первой минимальной системы выбран musl.
- Графическая среда не устанавливается автоматически. KDE Plasma рассматривается как дополнительный профиль.
- systemd и OpenRC планируются как отдельные варианты установки.
- Собственный формат пакетов — `.aet`.
- Debian-пакеты будут проверяться на совместимость. Конвертация не должна запускать maintainer scripts.
- Поддержка оборудования будет опираться на драйверы ядра Linux и отдельно учитываемые firmware-файлы.

Инструмент сборки проверяет SHA-256 загружаемых архивов. В `sources.lock` пока нет записей: версии исходников и контрольные суммы нужно проверить до добавления.

## Разработка

Подробности находятся в [архитектуре](docs/architecture.md), [плане разработки](docs/roadmap.md) и [описании сборочной системы](docs/build-system.md).

Нужен Python 3.11 или новее:

```sh
python3 tools/aether-build check
python3 -m unittest discover -s tests -v
```

Загрузки и результаты будущих сборок будут храниться в отдельном рабочем каталоге. Текущий инструмент не устанавливает пакеты и не изменяет систему разработчика.

## Поддержка оборудования

Совместимость зависит от конкретного устройства, конфигурации ядра, доступности firmware и условий лицензии. Нельзя заранее гарантировать работу каждого устройства. По мере тестирования будет публиковаться список проверенного оборудования и известных ограничений.

## Безопасность

- Собирать систему в отдельном рабочем каталоге, не в корне хостовой ОС.
- Проверять контрольные суммы исходников.
- Проверять загрузку и установку в QEMU до тестирования на реальном оборудовании.
- Не изменять существующую конфигурацию загрузчика без согласия пользователя и резервной копии.
- Сохранять лицензии и уведомления сторонних проектов.

## Лицензия

Лицензии собственных компонентов проекта ещё предстоит окончательно выбрать. Сторонние компоненты сохраняют исходные лицензии.
